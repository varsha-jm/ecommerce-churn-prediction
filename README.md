# 🛒 E-commerce Customer Churn Prediction

Predicting which customers are likely to churn using 
Machine Learning classification models.

## 📌 Problem Statement
Customer churn is a major challenge for e-commerce businesses. 
This project builds an ML model to identify at-risk customers 
so businesses can take proactive retention actions.

## 🔧 Tech Stack
- Python
- Pandas & NumPy
- Matplotlib
- Scikit-learn

## 📂 Project Structure
- 01_EDA.ipynb — Exploratory Data Analysis
- 02_preprocessing.ipynb — Data Cleaning & Feature Engineering
- cleaned_ecommerce_churn.csv — Processed Dataset
